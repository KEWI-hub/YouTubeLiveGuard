# YouTube Live Guard

ส่วนขยาย Chrome สำหรับตรวจคุณภาพไลฟ์ YouTube, วิเคราะห์สาเหตุที่กระตุก และ **กด LIVE ให้อัตโนมัติ** เพื่อกลับไปที่ Live Now

## ติดตั้ง
1. เปิด `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** → เลือกโฟลเดอร์ `youtube-live-guard`
4. รีเฟรชแท็บ YouTube ที่เปิดอยู่

## ทำงานอย่างไร
| เงื่อนไข | สิ่งที่ทำ |
|---|---|
| ภาพค้าง/บัฟเฟอร์เกิน 2 วิ | กด LIVE (ถ้าอยู่ Live Now แล้วจะ seek ใหม่เพื่อล้างบัฟเฟอร์ที่ค้าง) |
| กระตุกสั้นๆ ≥3 ครั้งใน 1 นาที | กด LIVE |
| ช้ากว่า Live เกิน 30 วิ | กด LIVE (ยกเว้นตอนที่คุณย้อนดูเอง) |
| เด้ง LIVE ≥3 ครั้งใน 2 นาที | (ถ้าเปิดไว้) ลดความละเอียด 1 ขั้น |

ตัวเลขทุกค่าปรับได้ในป๊อปอัป → "ตั้งค่า"

## ค่าที่วัด
ความละเอียด, บัฟเฟอร์, ระยะห่างจาก Live (`getProgressState().seekableEnd - current`), เฟรมตก, ความเร็วเน็ต (Stats for nerds), จำนวนครั้งที่กระตุกต่อนาที

## วิธีแก้ที่แนะนำ (แสดงในป๊อปอัปตามอาการ)
- **บัฟเฟอร์ต่ำ + กระตุก** → เน็ตไม่พอ: ลดความละเอียด, ปิดโปรแกรมดาวน์โหลด, ใช้สาย LAN
- **เฟรมตกสูง** → เครื่องถอดรหัสภาพไม่ทัน: เปิด Hardware acceleration ที่ `chrome://settings/system`, ปิดแท็บที่หนัก
- **เน็ตแรงแต่ยังกระตุก** → มักเป็นปัญหาต้นทางของผู้สตรีม
